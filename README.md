# Emotion Detector

## Project Name: AI-Based Emotion Detection Application

This project is an **AI-based web application** that detects emotions from text using the Watson NLP library. The application processes user-provided text and identifies the dominant emotion among five categories: **anger, disgust, fear, joy, and sadness**.

## Features
- Emotion detection using Watson NLP Emotion Predict function
- Web interface built with Flask
- Error handling for blank and invalid inputs
- Unit tests for all emotion categories
- Static code analysis with Pylint (10/10 score)

## Technologies Used
- Python
- Flask
- Watson NLP Library
- HTML/CSS/JavaScript (Bootstrap)
- Unittest

## How to Run
1. Clone the repository
2. Install dependencies: `pip install flask requests`
3. Run the server: `python server.py`
4. Open browser to `http://localhost:5000`
